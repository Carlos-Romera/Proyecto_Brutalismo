# PROYECTO_BRUTALISMO

Este es un proyecto de diseño web que explora la estética del **Brutalismo Digital**. Se enfoca en la honestidad de los materiales digitales y la eliminación de adornos innecesarios.

## 🧱 Características del Diseño
*   **Minimalismo Estructural**: Uso de layouts crudos y directos.
*   **Tipografía**: Se utiliza un peso tipográfico de 400 (Regular) para asegurar una lectura clara y equilibrada dentro del impacto visual del estilo.
*   **Funcionalidad**: Código limpio sin dependencias externas.

## 🛠️ Tecnologías
*   **HTML5**: Estructura semántica.
*   **CSS3**: Estilos personalizados (sin frameworks).
*   **JavaScript**: Interactividad básica.
